# Moodle Moderno - IFSP Araraquara

Interface alternativa, moderna e rápida para o Ambiente Virtual de Aprendizagem Moodle do IFSP Câmpus Araraquara.

---

## 🚀 Como Usar Agora (Sem Instalar Nada)

1. Vá até a pasta **`moodle-moderno`** na sua **Área de Trabalho**.
2. Abra o arquivo `index.html` no navegador (Google Chrome, Edge, etc.).
3. Na tela de login, informe o endereço do servidor Moodle, seu prontuário e sua senha.

---

## ☁️ Como Publicar na Vercel (Deploy Grátis em 1 Minuto)

### Opção 1: Pelo GitHub (Recomendado)
1. Crie um repositório no GitHub (ex: `moodle-moderno`).
2. Suba os arquivos desta pasta para o repositório.
3. Acesse [vercel.com](https://vercel.com) e clique em **"Add New Project"**.
4. Importe o repositório. A Vercel detectará o arquivo `index.html` e `vercel.json` automaticamente.
5. Clique em **Deploy**. Você terá um link HTTPS público (ex: `moodle-moderno.vercel.app`) para usar do celular ou de qualquer computador!

### Opção 2: Pelo Vercel CLI
Se tiver o Vercel CLI instalado:
```bash
vercel --prod
```

---

## 🗑️ Como Desinstalar / Apagar do Computador

Todo o projeto está **100% contido nesta única pasta**. Nenhum arquivo ou dependência foi instalado no seu sistema.

Para desinstalar:
- Basta **deletar a pasta `moodle-moderno` da Área de Trabalho** e esvaziar a Lixeira. Pronto!
